## 🚀 How to Open and View

### Option 1: Direct File Open
Double click `index.html` in your file explorer to open directly in any modern browser (`Chrome`, `Edge`, `Firefox`). All assets and pages use relative paths.

### Option 2: Run via NPM
```bash
# Start standard server
npm start

# Or run live-reloading dev server
npm run live
```
Then visit **`http://localhost:3000`** in your browser.
